# Oh My Ark Theme

Six native color themes with original SVG-derived backgrounds: Endfield, The Masses and Siesta, each in light and dark.

Install this VSIX, then run **Ark Theme: Open Control Panel**. The panel can save independent app choices or synchronize both selections. Codex requires the separate local Ark bridge for automatic application. Color themes work without any bridge or patch.

Enhanced workbench backgrounds are optional and use an explicit, reversible CSS patch. VS Code may report modified installation files; integrity checks are never suppressed. Native themes work with no installation modification.

Original fan-inspired designs; not affiliated with or endorsed by Hypergryph, Gryphline, Microsoft or OpenAI.
